# 09 每日任务 (Daily Tasks)

**页面ID**: `daily_tasks`
**分辨率**: 1600x900
**特征**: 顶部进度条 + 左侧任务分类标签 + 中央任务列表 + 底部弥弥观测站

## 页面特征（用于识别当前页面）

- 顶部有倒计时 "XX:XX:XX后刷新"
- 顶部有进度条: 每日评分 → 140，带里程碑节点 (20, 40, 60, 80, 100)
- 左侧有三个分类标签: 每日任务、周常任务、剧情任务
- 中央有任务列表（每行含任务描述、进度、奖励图标）
- 底部左侧有"弥弥观测站"按钮
- 顶部右侧有资源栏

## 文本可靠性

### STABLE（稳定文本 — 可用于页面识别）

- 左侧标签: "每日任务", "周常任务", "剧情任务"
- 进度条: "每日评分"
- 底部: "弥弥观测站"

### FLAKY（不稳定文本 — 不可用于页面识别）

- 刷新倒计时（04:26:43后刷新）
- 具体任务描述（可能随版本更新变化）
- 任务完成进度（0/1 等）
- 评分数值

## 导航关系

- **父页面**: 主大厅(main_hub) → 按 G 键
- **返回**: 点击 ◀ 返回箭头 (35, 35) 或按 ESC → main_hub
- **子页面**:
  - 各任务跳转 → 点击任务行的 ">" 箭头
  - 弥弥观测站 → 点击"弥弥观测站" (110, 820)
  - 周常/剧情任务为页内标签切换

## 备注

- 通过 G 键快捷键从主大厅直接进入
- 任务列表可滚动，每个任务行右侧有 ">" 箭头可跳转到对应功能
- 已完成任务会有勾选标记
- 进度条上的里程碑宝箱可在达到对应分数后领取
- 坐标基于 1600x900 分辨率，经像素扫描 + 实际点击验证
