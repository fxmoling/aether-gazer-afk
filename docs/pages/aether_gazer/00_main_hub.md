# 00 主大厅 (Main Hub)

**页面ID**: `main_hub`
**分辨率**: 1600x900
**特征**: 底部有一排导航按钮，左侧有功能菜单，顶部有资源栏，中央有角色坐在沙发上

## 页面特征（用于识别当前页面）

- 底部导航栏存在（修正者、探测、商店、公会、仓库、游园街）
- 右下角有"前往作战"按钮（金色/橙色）
- 顶部有等级和资源显示（体力、金币、钻石）
- 左侧有功能菜单（对策协议、进修企划、入职活动）
- 右上角有活动横幅（觉宙合等）

### 底部左侧横幅（滚动广告）

左下角有循环滚动的活动横幅：奇响派对、限时UP、稀绊之花、首充福利重置等。
这些是广告，**不要误认为是导航按钮**。

## 导航关系

- **来源**: 宿舍(dormitory) ← 点击返回键 (48, 48)
- **可达**:
  - 角色管理 → 点击"修正者" (675, 850)
  - 抽卡 → 点击"探测" (790, 850) ⚠️ 禁止操作
  - 商店 → 点击"商店" (910, 850)
  - 公会 → 点击"公会" (1025, 850)
  - 仓库 → 点击"仓库" (1140, 850)
  - 游园街 → 点击"游园街" (1257, 850)
  - 作战选择 → 点击"前往作战" (1465, 850) 或按 J 键
  - 每日任务 → 按 G 键
  - 邮件 → 按 H 键
  - 设置面板 → 按 Tab 键
  - 玩家信息 → 点击左上角头像 (50, 40)

## 备注

- UI 元素在闲置后会自动隐藏，需要点击屏幕唤醒
- 角色模型坐在沙发上占据屏幕中下部分，点击该区域会触发角色对话而非导航
- 底部导航栏是主要的页面切换入口
- 坐标基于 1600x900 分辨率，经像素扫描 + 实际点击验证
