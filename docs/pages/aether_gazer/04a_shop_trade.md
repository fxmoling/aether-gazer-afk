## 购买弹窗 (Purchase Popup)

点击商品后弹出的购买确认弹窗。

### 弹窗布局
- 左侧: 物品大图 + "持有: X"
- 右上: 物品名称 + 描述
- 右中: 数量控制行
- 右下: "本月限购 X/X" + 价格 + 购买按钮

### 控件坐标

| 控件 | 坐标 | 验证 | 功能 |
|------|------|------|------|
| 减号 (−) | (608, 624) | ⚠️ 未点击验证 | 数量减1 |
| 滑动条 | (679, 623) | ⚠️ 未验证 | 拖动设置数量 |
| 加号 (+) | (~975, 623) | ⚠️ 未点击验证 | 数量加1 |
| 最大 | (1038, 624) | ✅ 已验证 | 设置为最大可购数 |
| 购买 | (1234, 623) | ✅ 已验证 | 确认购买，成功后弹窗自动关闭 |
| 关闭 | ESC 或点击弹窗外 | ✅ | 取消 |

### 完整购买流程 ✅ 已实测验证 (2026-04-05)

```
hub → shop(940,855) → 交易区(89,817) → 每日采购(130,125)
→ 点击商品图标(350,230) → 弹窗打开
→ 最大(1038,624) → 数量变为限购上限, 价格同步更新
→ 购买(1234,623) → 购买成功, 弹窗关闭, 回到商品列表
```

**实测记录**: 维心情报 ×3, 花费 30000, 货币 1373.7K → 1343.7K ✅
