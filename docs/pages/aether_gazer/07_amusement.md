# 07 游园街 (Amusement Street / Dormitory Hall)

**页面ID**: `amusement`
**分辨率**: 1600x900
**特征**: 等距视角宿舍建筑 + 楼层选择器 + 底部功能按钮栏

## 页面特征（用于识别当前页面）

- 等距(isometric)视角显示宿舍建筑，可见多个楼层(1F-4F)
- 中央有"大厅"标签，Q版角色坐在其中
- 右侧有楼层选择器（1F-4F竖排按钮）
- 底部左侧有"导航"按钮（带指南针图标）
- 底部中央有"入住"六边形按钮
- 底部栏有: 游园任务、游园街面板、参观
- 左侧有角色信息（如 波塞冬 LV.1，带好感度指示器）
