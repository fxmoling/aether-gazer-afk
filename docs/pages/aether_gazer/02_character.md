# 02 修正者 (Character Management)

**页面ID**: `character`
**分辨率**: 1600x900
**特征**: 左侧角色列表 + 中央全身角色模型 + 右侧属性面板，左侧有属性/技能等标签页

## 页面特征（用于识别当前页面）

- 左侧有竖排角色标签页: 属性、技能、权钥、刻印、跃迁、神格、芯片
- 左侧有角色头像列表（竖向排列）
- 中央有角色全身模型
- 右侧有角色属性面板（战力指数、攻击力、防御力等）
- 顶部左侧有 "< C" 返回/刷新图标
- 底部有 培养攻略、超越、突破 按钮

## 文本可靠性

### STABLE（稳定文本 — 可用于页面识别）

- 左侧标签页: "属性", "技能", "权钥", "刻印", "跃迁", "神格", "芯片"
- 属性面板: "战力指数", "攻击力", "防御力", "生命值上限", "会心率"
- 底部按钮: "培养攻略", "超越", "突破"
- 其他: "熟练值", "等级"

### FLAKY（不稳定文本 — 不可用于页面识别）

- 角色名称（荷鲁斯等，随选中角色变化）
- 具体数值（战力、攻击力数字等）
- 等级数值
