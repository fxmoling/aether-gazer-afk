# 15 玩家信息 (Player Info)

**页面ID**: `player_info`
**分辨率**: 1600x900
**特征**: 叠加弹窗（主大厅背景可见）— 含头像、UID、等级、收集进度等

## 页面特征（用于识别当前页面）

- **这是一个叠加弹窗(overlay/popup)**，主大厅在背景中可见
- 左侧有玩家头像
- 右侧显示:
  - 玩家名称（带编辑图标）
  - UID
  - 等级 + 经验进度条
  - "设置标签"按钮
  - 个性签名
  - 矩阵公会（带链接）
  - 心愿展示（带链接）
- 底部有收集进度统计: 修正者、钥从、贴纸、成就（百分比+数值）
- 底部左侧有"用户中心"按钮

## 文本可靠性

### STABLE（稳定文本 — 可用于页面识别）

- 标签: "等级", "设置标签", "矩阵公会", "心愿展示"
- 收集分类: "修正者", "钥从", "贴纸", "成就"
- 按钮: "用户中心"

### FLAKY（不稳定文本 — 不可用于页面识别）

- 玩家名称（最宝贝的宝贝）
- UID（1086051425）
- 等级数值（95）
- 经验进度（7408/18465）
- 个性签名
- 公会名称（陵燕）
- 收集百分比和数值（53% 43/80 等）

## 可交互元素 — 已验证坐标 ✅

### 弹窗内

| 元素 | 作用 |
|------|------|
| 编辑图标（名称旁） | 编辑玩家名称 |
| 设置标签 | 设置展示标签 |
| 矩阵公会链接 | 跳转公会页面 |
| 心愿展示链接 | 跳转心愿展示 |
| 用户中心 | 进入用户中心 |

### 关闭弹窗

| 操作 | 作用 |
|------|------|
| 按 ESC 键 | 关闭弹窗，回到主大厅 |
| 点击弹窗外区域 | 关闭弹窗，回到主大厅 |

## 导航关系

- **父页面**: 主大厅(main_hub) → 点击左上角头像 (50, 40)
- **返回**: 按 ESC 或点击弹窗外区域 → main_hub
- **子页面**:
  - 公会 → 点击"矩阵公会"链接
  - 用户中心 → 点击"用户中心"

## 备注

- 这是叠加弹窗，不是独立页面
- 收集进度统计是了解账号状态的重要信息源
- 当前数据: 修正者 53% (43/80), 钥从 21% (24/110), 贴纸 15% (11/71), 成就 43% (200/463)
- 关闭方式: ESC 键或点击弹窗外区域
- 坐标基于 1600x900 分辨率
