# 08b 战斗流程 (Battle Flow)

**页面ID**: `battle_flow` (多阶段流程，非单一页面)
**设计分辨率**: 1600x900
**验证状态**: ✅ 已实测验证 (2026-04-05)

## 概述

从选关到战斗完成的完整流程，涉及多个阶段/页面切换。

```
关卡地图 → 准备作战 → 连续战斗提示(可选) → 编队界面 → 作战开始
→ [剧情(可选)] → 战斗 → [剧情(可选)] → 结算 → 下一关/返回地图
```

---

## 阶段 1: 准备作战

在关卡地图中，点击节点后右侧面板出现关卡详情。

| 元素 | 坐标 | 验证 | 功能 |
|------|------|------|------|
| 准备作战按钮 | **(1350, 840)** | ✅ | 进入编队或连续战斗提示 |
| 关卡名称 | 右侧面板上方 | ✅ | 显示当前关卡名(如"蛇神唤醒") |
| 关卡目标 ×3 | 右侧面板中部 | ✅ | 蓝色三角=已完成, 灰色三角=未完成 |
| 体力消耗 | 右侧面板下方 | ✅ | 如"40" |
| 当前体力 | 右上角 | ✅ | 如"273/240" |

## 阶段 2: 连续战斗提示 (条件触发)

当后续多关为连续战斗时弹出此提示。

| 元素 | 坐标/键 | 验证 | 功能 |
|------|---------|------|------|
| 取消 | **ESC** | ✅ | 返回关卡地图 |
| 进行连续战斗 | **Enter** | ✅ | 进入编队界面 |
| 体力"+" | (~1530, 36) | ✅ | 进入体力补充页面 |

提示内容:
- "后续X关为连续战斗，确保最佳体验需要消耗「咚咚值」×Y"
- 通关奖励预览（物品图标+数量）

## 阶段 4: 剧情/过场 (Cutscene)

主线关卡在战斗前/后可能有剧情对话。

### 剧情界面布局

| 元素 | 坐标/键 | 验证 | 功能 |
|------|---------|------|------|
| 对话日志 (R) | 左上 (~25, 25) | ✅ | 打开对话日志 |
| 自动播放 | 右上 (~1340, 25) | ✅ | "自动" 按钮 |
| 播放速度 | 右上 (~1400, 25) | ✅ | ▶ 按钮 |
| 跳过 | 右上 (~1490, 25) | ✅ | "跳过" 按钮 |
| 快进 | 右上 (~1565, 25) | ✅ | ">>" 按钮 |
| 信息 | 右侧 (~1545, 55) | ✅ | (i) 按钮 |
| Space | 右下 | ✅ | 推进对话一行 |
| ESC | 右侧 (~1580, 55) | ✅ | 打开跳过确认弹窗 |

### 跳过流程 (推荐自动化方式)

```
ESC → 弹出"跳过剧情"确认 → Enter确认
```

跳过确认弹窗:
- 标题: "跳过剧情"
- 内容: 章节名 + 剧情摘要
- "是否跳过剧情章节"
- 取消(ESC) / 确定(Enter)

> ⚠️ 注意: 战斗前和战斗后都可能有剧情段落，需要多次执行跳过流程。

## 阶段 5: 战斗 (Combat)

3D 实时战斗场景。

### 操作按键

| 键 | VK Code | 功能 |
|----|---------|------|
| W/A/S/D | 0x57/0x41/0x53/0x44 | **移动** |
| Space | 0x20 | **闪避** |
| J | 0x4A | **普通攻击** |
| U | 0x55 | 技能 |
| I | 0x49 | 技能 |
| O | 0x4F | 技能 |
| R | 0x52 | **大招** (终极技能) |
| 1 | 0x31 | 连携 (combo 1) |
| 2 | 0x32 | 连携 (combo 2) |

### 自动化策略

**循环按 J → J → U → I → O → R → 1 → 2，间隔 0.3 秒。** J(普攻)应多按几次作为主要输出，穿插技能和大招。不需要精细操作，暴力按键即可通关低难度关卡。

### 已知问题

- R 键在非战斗状态可能触发其他 UI（如对话日志），需注意状态判断
- 战斗加载时有黑屏过渡，此时按键无效但不会造成问题
- 连续战斗中关卡间可能有短暂加载/过渡

战斗完成后:

## 异常处理

### 网络断开

| 阶段 | 表现 | 处理 |
|------|------|------|
| 战斗中/加载中 | "网络连接失败，请检查网络设置后尝试重新登录" | Enter确认 |
| 确认后 | 回到登录界面: "深空之眼" + "点击任意区域进入游戏" | 点击任意位置 |
| 重新登录 | 公告弹窗（全屏活动图） | 点击关闭，**不要按ESC**（会触发退出游戏确认） |
| 退出确认误触 | "是否退出游戏？" 取消/确定 | **ESC取消** |
| 最终 | 回到 main_hub | 继续操作 |

> **重要**: 登录后的公告界面，ESC会触发"退出游戏"确认。应该**点击公告关闭按钮**而不是按ESC。

### 体力不足

- 连续战斗即使体力不足也可以进入
- 推荐: 在连续战斗提示页面，点击体力"+"补充后再开始

## 完整自动化流程 (主线连续战斗)

```
1. 关卡地图 → 点击目标节点
2. 点击准备作战 (1350, 840)
3. [如果连续战斗提示] → Enter 确认
4. 编队界面 → Enter 开始 (作战开始)
5. [如果独立剧情] → ESC → Enter 跳过
6. [如果关卡内探索] → WASD移动到交互物体 → Space推进对话
7. 战斗中 → 循环按 J/J/U/J/I/J/O/R/1/2 (间隔0.25s)
8. [如果修正者复活弹窗] → Enter确认复活(消耗可接受)
9. [如果战后剧情] → ESC → Enter 跳过
10. [如果连续战斗下一关] → 重复步骤 5-9
11. 全部完成 → 结算 → 返回关卡地图
12. [如果任务失败] → ESC关闭 → 返回关卡地图
```

### 状态检测建议

需要能识别当前处于哪个阶段:
- **独立剧情**: 检测右上角"跳过"/"自动"按钮
- **关卡内对话**: 底部对话框存在但无顶部跳过按钮栏
- **关卡内探索**: WASD控制提示可见 + 无敌人
- **战斗**: 检测战斗HUD元素(J/U/I/O按键提示)
- **加载**: 检测黑屏(平均亮度<20)
- **弹窗**: 检测白色中央弹窗 + 底部按钮
- **修正者复活**: 模板匹配"修正者复活"
- **任务失败**: 红色调 + "任务失败"文字
- **关卡地图**: 检测"准备作战"按钮

> 完整异常处理目录见 `99_anomaly_catalog.md`
