# 12 对策协议 (Tactics Protocol / Battle Pass)

**页面ID**: `tactics`
**分辨率**: 1600x900
**特征**: 顶部等级进度条 + 双轨奖励（基础/进阶合约）+ 底部任务/商店标签

## 页面特征（用于识别当前页面）

- 顶部左侧有 "< C" 返回/刷新图标
- 顶部有等级显示（如"26级"）和进度条
- 有经验值和本周上限显示: 经验值 XXX/XXX, 本周经验上限 XXX/XXX
- 顶部右侧有"购买等级"按钮
- 中央有双轨奖励展示:
  - 基础合约 (Basic Contract) — 免费轨
  - 进阶合约 (Advanced Contract) — 付费轨
- 奖励等级横向排列（27, 28, 29, 30, 31...）
- 底部有剩余天数和活动日期
- 底部有标签: 任务、(图标)、商店
- 左侧有角色立绘

## 文本可靠性

### STABLE（稳定文本 — 可用于页面识别）

- 合约名称: "基础合约", "进阶合约"
- 按钮: "购买等级"
- 数据标签: "经验值", "本周经验上限"
- 底部标签: "任务", "商店"

### FLAKY（不稳定文本 — 不可用于页面识别）

- 等级数值（26级）
- 经验值数值（200/1000）
- 本周上限数值（10200/15000）
- 剩余天数（本期剩余 37天）
- 活动日期（2026/04/02 - 2026/05/11）
- 奖励内容

## 导航关系

- **父页面**: 主大厅(main_hub) → 点击"对策协议" (100, 170)
- **返回**: 点击 ◀ 返回箭头 (35, 35) → main_hub
- **子页面**:
  - 任务列表 → 点击底部"任务"标签
  - 商店 → 点击底部"商店"标签

## 备注

- 对策协议即战斗通行证(Battle Pass)系统
- 基础合约为免费轨道，进阶合约需付费解锁
- "购买等级"按钮为付费功能，自动化中**不应点击**
- 奖励等级可左右滑动浏览
- 坐标基于 1600x900 分辨率
