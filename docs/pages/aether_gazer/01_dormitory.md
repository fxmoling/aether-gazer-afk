# 01 宿舍 (Dormitory)

**页面ID**: `dormitory`
**分辨率**: 1600x900
**截图**: `assets/aether_gazer/screenshots/current_state.png`
**特征**: 角色在房间中，背景为宿舍家具，UI 极简（仅顶部返回和设置按钮）

## 页面特征（用于识别当前页面）

- 背景是室内场景（沙发、壁炉、窗户等）
- 角色站立/坐在宿舍中
- UI 极简：仅在点击后显示少量按钮
- 底部有音乐播放提示（"正在播放 XXX"）
- 右下角显示时间和日期

## 可交互元素

**注意**: 宿舍页面的 UI 默认隐藏，需要**点击屏幕任意位置**后显示，约 5-10 秒后自动隐藏。

### 点击唤醒后可见的元素

| 元素 | 坐标中心(x,y) | 尺寸约(w,h) | 作用 | 目标页面 |
|------|-------------|-----------|------|---------|
| ◀ 返回按钮 (chevron) | (48, 48) | (60, 60) | 返回上一页 (主大厅) | main_hub |
| ⚙ 设置按钮 (gear) | (1555, 48) | (50, 50) | 打开设置 | settings |

### 场景内容（非交互 — 不要点击）

- 角色模型（宿舍中的角色立绘/3D 模型）
- 家具（沙发、桌子、壁炉等）
- 窗外夜景
- 地板纹理

## 导航关系

- **来源**: 主大厅(main_hub) → 点击某个入口（具体按钮待确认）
- **可达**:
  - 主大厅 → 点击 ◀ 返回按钮 (48, 48)
  - 设置 → 点击 ⚙ 设置按钮 (1555, 48)

## 备注

- 这是游戏的"休闲"页面，不是日常任务的必经之路
- UI 自动隐藏机制：需要在点击唤醒后立即操作
- 坐标基于 1600x900 分辨率
