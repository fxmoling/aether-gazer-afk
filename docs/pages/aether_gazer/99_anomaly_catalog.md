# 异常情况目录 (Anomaly Catalog)

**用途**: 纯代码级别的错误恢复参考。没有LLM，所有异常必须用规则匹配+固定流程处理。
**更新**: 2026-04-05

---

## 1. Hub Idle 模式 (音乐播放器)

**触发条件**: Hub页面闲置一段时间后自动进入
**表现**:
- 所有UI元素（顶栏、底栏、侧栏按钮）隐藏
- 只显示角色模型 + 时钟 + 左下角"正在播放"
- 可能左上角出现返回箭头 ◀
- 键盘快捷键(J/G/H/Tab)全部失效

**检测方法**:
- Hub页面模板匹配失败（UI不可见）
- 检测左下角"正在播放"文字/图标
- 右下角显示大字时钟

**恢复方法**:
1. 点击返回箭头 (35, 35) → 恢复正常hub
2. 或点击屏幕边缘（避开角色hitbox区域 x=650-930）

**注意**: 点击屏幕中央(800,450)会触发角色模型hitbox，可能进入宿舍等子页面而非恢复UI。

## 2. Hub 角色模型 Hitbox

**触发条件**: 在Hub页面点击中央区域 (x≈650-930)
**表现**: 进入宿舍大厅(dormitory)或角色交互，而非点击底部导航栏
**检测方法**: 预期导航到目标页面但模板匹配失败
**恢复方法**: 
1. ESC / 三角返回 (35,35) 返回hub
2. 导航栏按钮尽量点击靠右(x>940)避开角色区域

---

## 3. 网络断开

**触发条件**: 网络不稳定，可在任何阶段出现
**表现**:
- 弹窗: "网络连接失败，请检查网络设置后尝试重新登录"
- 只有一个"确定"按钮(Enter)

**检测方法**:
- 白色弹窗 + 居中单按钮（无"取消"按钮）
- 模板匹配"网络连接失败"文字

**恢复流程**:
```
Enter → 登录界面 → 点击任意位置(避免中央) → 公告弹窗
→ 点击关闭(不要按ESC!) → 可能多个公告 → hub
```

**关键**: 登录界面/公告界面按ESC = 触发"退出游戏"确认！

---

## 4. 退出游戏确认 (误触)

**触发条件**: 在登录界面/公告界面按ESC
**表现**: "是否退出游戏？" 取消(Esc)/确定(Enter)
**检测方法**: 模板匹配"退出游戏"文字
**恢复方法**: ESC取消

---

## 5. 关卡内探索/交互节点

**触发条件**: 某些主线关卡(如6-10"小七")有探索阶段
**表现**:
- 3D场景中出现交互物体（白色球体+光柱+底部圆圈等）
- 底部显示WASD移动控制 + Q/E镜头旋转
- 无敌人，无战斗HUD的攻击提示
- 角色站在原地等待移动

**检测方法**:
- 检测底部左侧WASD控制提示可见
- 无敌人HP条/战斗倒计时
- 场景中有发光交互物体

**处理方法**:
1. WASD朝各方向移动探索（自动寻路不可用）
2. 接近交互物体后自动触发对话/剧情
3. 触发后的对话用Space逐行推进（不能ESC跳过）

**对自动化的影响**: 这是最难自动化的部分。纯代码需要：
- 检测交互物体位置（模板匹配或颜色检测）
- 计算移动方向和持续时间
- 或采用随机游走策略直到触发交互

---

## 6. 关卡内对话 (不可跳过)

**触发条件**: 关卡内交互后触发的对话
**表现**:
- 底部对话框（深色背景 + 角色头像 + 名字 + 对话文字）
- 无顶部"跳过"/"自动"按钮栏
- 右下角Space提示

**检测方法**:
- 底部有对话框但顶部无跳过按钮
- 与独立剧情区分：独立剧情有完整的R/U/S/自动/跳过按钮栏

**处理方法**: Space逐行推进，重复直到对话结束

**注意**: Space在战斗中是闪避键，推进对话时如果误判状态会触发闪避

---

## 7. 独立剧情/过场 (可跳过)

**触发条件**: 战斗前后的独立剧情段落
**表现**:
- 全屏剧情场景
- 顶部有完整按钮栏: R(日志), U, S, 自动, ▶, 跳过, >>
- 右下角Space推进，右侧有i按钮和Esc按钮

**检测方法**: 检测顶部右侧"跳过">>"按钮存在

**处理方法**: ESC → "跳过剧情"确认弹窗 → Enter确认

---

## 8. 修正者复活弹窗 (战斗死亡)

**触发条件**: 战斗中角色全灭
**表现**:
- 弹窗: "修正者复活"
- "是否消耗「艾因索菲币」×100 复活？"
- 取消(Esc) / 确定(Enter)
- 右上角显示当前货币数量

**检测方法**: 模板匹配"修正者复活"文字

**处理方法**: **Enter确认复活** — 艾因索菲币×100消耗可接受
**备注**: 如果多次复活仍失败，最终会进入任务失败画面

---

## 9. 任务失败画面

**触发条件**: 战斗失败（取消复活后）
**表现**:
- 红色调全屏: "任务失败"
- 关卡名 + 战斗时长
- Tips提示（升级、换装等建议）
- "点击空白处关闭" + Esc

**检测方法**: 检测"任务失败"文字或红色调全屏
**处理方法**: ESC关闭 → 返回关卡地图

---

## 10. 连续战斗提示

**触发条件**: 主线某些关卡有多关连续战斗
**表现**:
- "后续X关为连续战斗，确保最佳体验需要消耗「咚咚值」×Y"
- 奖励预览
- 取消(Esc) / 进行连续战斗(Enter)

**检测方法**: 模板匹配"连续战斗提示"文字
**处理方法**: 
- 体力充足 → Enter确认
- 体力不足 → 点击体力"+"补充 → 再Enter

---

## 11. 登录后公告弹窗

**触发条件**: 每次登录后
**表现**: 全屏活动宣传图，可能有多个
**检测方法**: 全屏图片，无常规UI元素
**处理方法**: 点击关闭（通常右上角X或屏幕任意位置），**不要按ESC**

---

## 异常处理优先级 (代码实现)

每次截图后，按以下优先级检测：

1. **网络错误** → Enter确认 → 重新登录流程
2. **退出游戏确认** → ESC取消
3. **修正者复活** → Enter确认复活（消耗可接受）
4. **任务失败** → ESC关闭
5. **跳过剧情确认** → Enter确认
6. **独立剧情** → ESC触发跳过
7. **连续战斗提示** → Enter确认
8. **关卡内对话** → Space推进
9. **黑屏/加载** → 等待
10. **战斗中** → 按攻击键循环
11. **关卡内探索** → WASD移动探索
12. **Hub idle** → 点击(35,35)恢复

## 状态检测方法 (禁止像素亮度!)

**禁止**: np.mean(img), 像素颜色计数, 亮度阈值判断
**必须使用**:

### 1. OCR 文字识别 (优先)

每个状态都有可识别的固定文字:

| 状态 | 识别文字 | 位置区域 |
|------|---------|---------|
| 网络错误 | "网络连接失败" | 中央弹窗 |
| 退出确认 | "退出游戏" | 中央弹窗 |
| 修正者复活 | "修正者复活" | 弹窗标题 |
| 任务失败 | "任务失败" | 屏幕中上 |
| 跳过剧情确认 | "跳过剧情" | 弹窗标题 |
| 独立剧情 | "跳过" 或 "自动" | 右上角 (1300-1600, 0-60) |
| 连续战斗提示 | "连续战斗提示" | 弹窗标题 |
| 编队/准备作战 | "作战开始" 或 "准备作战" | 右下角按钮文字 |
| 关卡地图 | "完成进度" | 左下角 |
| 关卡内对话 | 对话框中角色名 | 底部 (100-800, 700-800) |
| 战斗HUD | "暂停" | 左下角 (0-150, 850-900) |
| Hub | "前往作战" | 底部导航栏 |

### 2. cv2.matchTemplate 模板匹配 (文字不可靠时)

- 战斗HUD的技能图标区域
- 特定UI签名区域（已有15个页面的V2模板）
- 交互物体的视觉特征

### 3. 其他opencv方法

- cv2.findContours — 定位按钮/卡片边界
- 颜色空间转换(HSV) — 仅在需要定位特定颜色物体时使用（如交互节点的发光效果）
