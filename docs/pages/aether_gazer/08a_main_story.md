## 页面布局

- **中央**: 当前选中章节的大幅宣传卡片（含章节号、章节名、收集度%）

## 章节选择 — 两步定位法 ✅

精确选择任意章节的推荐方法：

### Step 1: 时间线节点跳转到大致范围

底部时间线的分组节点**可以直接点击跳转**，跳到该分组的第一个章节。

时间线本身也可横向滚动，先让目标分组节点露出来再点击。

| 节点 | 坐标 | 验证 |
|------|------|------|
| 第1-5章 | (~130, 860) | ⚠️ 估算 |
| 第6-9章 | **(330, 860)** | ✅ 已验证 — 跳转到第6章 |
| 第10-11章 | (~470, 860) | ⚠️ 估算 |
| 其他... | ... | 时间线滚动后坐标会变 |

> 注意: 时间线可滚动，节点的实际 x 坐标随滚动位置变化。

### Step 2: 点击右侧露头卡片逐章微调

跳转到分组后，目标章节可能不是当前显示的。右侧边缘会**露出下一章卡片的一角**。

- **点击右侧露头** (~1520, 400) → 前进1章，动画需 **2-3秒**
- **点击左侧露头** (~80, 400) → 后退1章
- 重复此操作逐章推进，直到目标章节居中

✅ 已验证: 第6章 → 点击右侧露头 → 精确到达第7章

### 方法 3: 中央区域横向滑动（不推荐）

swipe 步幅不稳定，可能一次跳过多个章节。仅在粗略浏览时使用。

| 操作 | 方向 | 效果 |
|------|------|------|
| swipe(400,450 → 1200,450) | 从左往右 | 翻到更早章节 |
| swipe(1200,450 → 400,450) | 从右往左 | 翻到更晚章节 |

## 章节关卡地图（子页面）

点击中央卡片后进入该章节的关卡地图。

### 布局
- **中央**: 关卡节点地图，节点用连线表示先后顺序，可分叉
- **左下角**: "完成进度 X/Y"（如 17/35）
- **右上角**: 难度"普通" + 收集度"%"
- **左上角**: 三角返回 + 圆形返回
- 地图可**横向滑动**查看更多关卡

### 节点状态识别 ✅

每个节点下方有 label（如"6-7"），label 左侧有一个**三角形标记**：

| 三角颜色 | 含义 |
|---------|------|
| **蓝色** ▶（全蓝或部分蓝） | 已通关 |
| **灰色** ▷ | 未通关 |

> 红色圆圈是一种节点视觉样式（如 boss 关），不表示"当前进度"。
> 判断通关状态只看三角标记颜色。

### 点击节点

点击任意节点 → 右侧弹出关卡详情面板：
- 关卡编号 + 名称
- 关卡目标（3个星级条件，灰色三角=未完成，蓝色=已完成）
- **"准备作战"** 橙色按钮（右下角）
- 体力消耗数量（如 40，剧情关为 0）
- 右上角: 当前体力 (如 151/240)

### 准备作战 → 连续战斗提示 ✅

点击"准备作战"后，如果后续多关为连续战斗，会弹出提示：

- "后续X关为连续战斗，确保最佳体验需要消耗「咚咚值」×Y"
- 显示通关奖励预览
- **取消** (Esc) / **进行连续战斗** (Enter)
- **右上角体力 "+" 按钮** (~1530, 36) → 点击可进入体力补充页面

> 体力不足也可以进入连续战斗，只是不够连贯。
> 用户可配置是否自动补充体力。

### 体力补充页面 ✅ 已实测验证

从连续战斗弹窗右上角体力 "+" (~1530, 36) 进入。

**顶部3个Tab** (坐标 y≈155):

| Tab | 坐标 | 优先级 | 说明 |
|-----|------|--------|------|
| 冷却剂 | **(350, 155)** | ② 兜底 | 消耗冷却剂道具补充体力 |
| 移转之辉 | (~760, 155) | ⛔ 禁止 | 消耗移转之辉（稀有货币），永远不碰 |
| 每日补给 | **(1100, 155)** | ① 优先 | 每日免费领取（上午11:00/下午18:00各30点） |

**使用优先级**: 每日补给（免费）→ 冷却剂（道具）→ ~~移转之辉~~（禁止）

#### 冷却剂 Tab 操作 ✅

1. 点击物品图标 → 物品左上角显示选中数量"1"和"−"按钮
2. 右侧大数字实时更新将补充的咚咚值（如"120"）
3. 底部显示"是否消耗以上材料补充 X 咚咚值"
4. 可以选择多个/多种物品，数值累加
5. **确定** (Enter) / **取消** (Esc)

> 实测: 大冷却剂 = 120 咚咚值/个
> 体力可以超过上限（153 + 120 = 273/240 ✅）
> 确认后自动回到前一个弹窗（连续战斗提示）

#### 每日补给 Tab

- 每日上午 11:00 后可领取: 咚咚值福利包 30点
- 每日下午 18:00 后可领取: 咚咚值福利包 30点
- 未到时间显示倒计时

#### 移转之辉 Tab ⛔

- 25 移转之辉 → 60 咚咚值
- 今日剩余可兑换 10/10
- **禁止使用** — 移转之辉是稀有货币

### 地图滚动

- swipe(1200,450 → 400,450) → 向右查看更晚的关卡
- swipe(400,450 → 1200,450) → 向左查看更早的关卡
- 最新未通关关卡一般在地图最右端
