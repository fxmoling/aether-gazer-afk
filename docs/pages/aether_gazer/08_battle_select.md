## 情报 Tab（默认）

### 布局
- **左侧大图**: 主线剧情入口（占屏幕约左 1/3）
- **右上**: 限时副本卡片×4（FLAKY，忽略，可从其他 tab 访问）
- **右下**: 支线剧情入口

### 可交互元素

| 元素 | 坐标 | 验证 | 目标 |
|------|------|------|------|
| 主线剧情入口 | **(533, 450)** | ✅ | → 主线章节选择页 |
| 支线剧情入口 | **(1010, 625)** | ✅ | → 支线剧情选关页 |
| 右上限时副本×4 | — | — | 忽略（FLAKY，可从其他 tab 访问） |

> 主线入口坐标 = 屏幕 x×1/3, y×1/2 的中心区域

### 主线章节选择页（子页面）

进入后显示：
- **中央**: 章节卡片（含章节名、收集度%）
- **底部**: 章节时间线（前1-5章 → 第6-9章 → ... → 第20-22章）
- **右上**: "情报库索引"按钮 + 难度选择（"普通"）
- 左右滑动切换章节
- 返回：三角 ◀ (35, 35) → 情报 tab

### 支线剧情选关页（子页面）

进入后显示：
- **中央**: 支线大图 + 名称 + 收集率
- **底部**: 章节缩略图列表
- **右上**: "情报库索引"按钮
- 返回：三角 ◀ (35, 35) → 情报 tab

### 文本可靠性
- **STABLE**: "主线剧情", "支线剧情", "情报库索引"
- **STABLE**: "迭代校验", "梦境再构", "潜质觉醒", "介质撷取"
- **FLAKY**: 章节名、活动横幅、支线名称
