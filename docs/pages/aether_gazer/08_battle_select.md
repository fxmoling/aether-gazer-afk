# 08 作战选择 (Battle Select)

**页面ID**: `battle_select`
**分辨率**: 1600x900
**特征**: 左侧主线剧情卡 + 中央作战模式卡片 + 底部五个分类标签

## 页面特征（用于识别当前页面）

- 左侧有主线剧情大卡片（含章节名和立绘）
- 中央有横向排列的作战模式卡片（迭代校验、梦境再构、潜质觉醒、介质攫取等）
- 底部有五个分类标签: 情报、常驻、物资、刻印、挑战
- 顶部左侧有 "< C" 返回/刷新图标
- 可能有活动横幅 "活动期间 提前开放"
- 底部右侧可能有支线剧情入口

## 文本可靠性

### STABLE（稳定文本 — 可用于页面识别）

- 底部标签: "情报", "常驻", "物资", "刻印", "挑战"
- 左侧: "主线剧情"
- 作战模式名（多数稳定）: "迭代校验", "梦境再构", "潜质觉醒", "介质攫取"

### FLAKY（不稳定文本 — 不可用于页面识别）

- 章节名（第二十四章 览宙合（前篇）— 随游戏进度变化）
- 活动横幅（"活动期间 提前开放"）
- 支线剧情名称（洞仙扫花时）

## 导航关系

- **父页面**: 主大厅(main_hub) → 点击"前往作战" (1465, 850) 或按 J 键
- **返回**: 点击 ◀ 返回箭头 (35, 35) → main_hub
- **子页面**:
  - 主线关卡 → 点击主线剧情卡 (250, 400)
  - 各作战模式 → 点击对应卡片
  - 底部标签切换为页内切换

## 备注

- 作战模式卡片可能需要左右滑动查看更多
- 底部标签切换是页内内容变化，不产生新页面
- "情报"标签通常为默认选中状态
- 卡片区域位置可能随标签切换而变化
- 坐标基于 1600x900 分辨率，经像素扫描 + 实际点击验证
