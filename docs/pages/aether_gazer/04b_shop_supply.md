## 每日免费体力药领取 ✅ 已实测验证 (2026-04-05)

**日常补给** tab 中的第一个商品是 **"每日应急冷却包"**：
- 内容：冷却剂·小号 ×1（体力药）
- 价格：**免费**
- 限购：今日限购 1/1（每天刷新）
- 领取后该卡片消失，商品列表重排

### 完整领取流程

```
hub → shop(940,855) → 补给区(399,816)
→ 日常补给 tab(560,130)
→ 点击免费冷却包卡片(350,290)
→ 弹窗: 确定(Enter 0x0D) 或 点击确定按钮
→ 获得物品展示 → 点击屏幕继续
→ 回到日常补给列表（免费卡片消失）
```

### 弹窗结构（与交易区不同）

| 元素 | 操作 | 验证 |
|------|------|------|
| 取消 | ESC 或点击左侧按钮 | — |
| 确定 | **Enter (0x0D)** 或点击右侧橙色按钮 | ✅ |

### 获得物品展示

- 全屏展示获得的物品
- "点击屏幕继续" 提示
- 点击任意位置或 ESC 关闭

### 注意事项

- 免费包的卡片位置是 **(350, 290)**，但它是第一个卡片的位置——如果已领取，该位置会变成其他付费商品
- 领取前应先检查第一个卡片是否显示"免费"标签
- 建议用模板匹配识别"免费"标签，而不是固定坐标点击

## 其他内容 — 禁止操作

### 内容区（限时补给/组合补给等）

两行多列的礼包卡片网格，每张卡片包含：
- 礼包图片 + 折扣标签（如"2.3折"）
- 限时标签（如"53天"）
- 限购数量（如"限购 1/1"）
- 礼包名称
- 价格（**真实货币**）

### 禁止触发的元素

| 元素 | 原因 |
|------|------|
| 所有付费礼包卡片 | 涉及真实充值 |
| 累计充值按钮 | 涉及真实充值 |
| 左侧 tab（角色换装/移转观测/首充福利）| 不需要操作 |
