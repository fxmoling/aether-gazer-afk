# 14 入职活动 (Events / Newbie Activities)

**页面ID**: `events`
**分辨率**: 1600x900
**特征**: 左侧活动分类标签 + 顶部日期标签 + 中央任务列表 + 底部进度奖励

## 页面特征（用于识别当前页面）

- 顶部左侧有 "< C" 返回/刷新图标
- 左侧有活动分类标签: 入职签到、新人课程、升级奖励、日常委托
- 顶部有日期标签（第5天、第6天、第7天...）
- 中央有任务列表（各任务含描述和完成进度）
- 底部有完成进度条 "完成进度 XXX/XXX"
- 底部有奖励领取按钮（已领取/可领取）
- 有角色奖励宣传（如"完成全部课程任务即可获得「潮音·波塞冬」"）

## 文本可靠性

### STABLE（稳定文本 — 可用于页面识别）

- 左侧标签: "入职签到", "新人课程", "升级奖励", "日常委托"
- 进度: "完成进度"

### FLAKY（不稳定文本 — 不可用于页面识别）

- 日期标签（第5天、第6天等 — 随天数推进）
- 任务描述（通关主线普通难度第11章等）
- 完成进度数值（110/105）
- 奖励角色名称（潮音·波塞冬）
- 奖励物品（移转之辉、探测凭证等）

## 可交互元素 — 已验证坐标 ✅

### 顶部导航

| 元素 | 坐标中心(x,y) | 作用 | 目标页面 |
|------|-------------|------|---------|
| ◀ 返回箭头 | (35, 35) | 返回主大厅 | main_hub |

### 左侧活动分类标签

| 元素 | 作用 |
|------|------|
| 入职签到 | 入职签到任务（默认选中） |
| 新人课程 | 新人课程任务列表 |
| 升级奖励 | 升级奖励领取 |
| 日常委托 | 日常委托任务 |

### 顶部日期标签

日期标签横向排列，可点击切换不同天的任务。

### 底部奖励

底部有已完成阶段的奖励按钮（已领取显示"已领取"，可领取显示领取按钮）。

## 导航关系

- **父页面**: 主大厅(main_hub) → 点击"入职活动" (100, 370)
- **返回**: 点击 ◀ 返回箭头 (35, 35) → main_hub
- **子页面**: 各标签为页内切换

## 备注

- 入职活动为新手引导/阶段性活动系统
- 任务完成进度可能显示为已完成（如 110/105 表示已超额完成）
- 已领取的奖励按钮会变灰并显示"已领取"
- 此页面内容随游戏阶段变化，新手期后部分内容可能不再显示
- 坐标基于 1600x900 分辨率
