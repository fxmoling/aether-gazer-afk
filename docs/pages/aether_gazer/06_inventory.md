# 06 仓库 (Inventory) ⚠️ SURFACE ONLY

**页面ID**: `inventory`
**分辨率**: 1600x900
**特征**: 左侧分类标签 + 中央物品网格 + 右侧物品详情
**⚠️ 安全级别**: 仅浏览表面，**不要点击物品或使用按钮**

## 页面特征（用于识别当前页面）

- 顶部左侧有 "< C" 返回/刷新图标
- 左侧有分类标签: 材料、情报、刻印、礼物、回忆
- 中央有物品图标网格（约5x7）
- 右侧有物品详情面板（物品名、持有量、描述）
- 顶部右侧有资源栏（体力、金币、钻石）
- 底部右侧有"使用"按钮

## 文本可靠性

### STABLE（稳定文本 — 可用于页面识别）

- 左侧标签: "材料", "情报", "刻印", "礼物", "回忆"
- 右侧面板: "持有量"
- 底部按钮: "使用"

### FLAKY（不稳定文本 — 不可用于页面识别）

- 物品名称（冷却剂·大号等）
- 持有量数值
- 物品描述
- 过期时间
- 标签上的提示角标（23天等）

## 可交互元素

## 导航关系

- **父页面**: 主大厅(main_hub) → 点击"仓库" (1140, 850)
- **返回**: 点击 ◀ 返回箭头 (35, 35) → main_hub
- **子页面**: 无（禁止深入操作）

## 备注

- ⚠️ **安全警告**: 此页面仅用于浏览，禁止点击物品或"使用"按钮
- "使用"按钮可能消耗不可恢复的游戏资源
- 左侧分类标签切换可接受，但不要选中物品
- 材料标签可能有角标提示（如"23天"表示有即将过期的物品）
- 坐标基于 1600x900 分辨率
