## 靠运气成功的部分 ⚠️

### 1. 探索节点交互
- **问题**: W键随机前进碰巧走到了交互物体
- **风险**: 换个地图布局、交互物体在侧面或后面时会失败
- **改进方向**: 视觉检测交互物体位置 → 计算移动方向 → 或360度旋转扫描

### 2. 连续战斗提示确认
- **问题**: txt_continuous_battle模板匹配未触发，靠unknown的Enter确认
- **原因**: 可能截图时机问题，或模板裁剪区域偏差
- **改进方向**: 重新裁剪模板，或添加"进行连续战斗"按钮文字模板

### 3. 暂停菜单误判
- **问题**: 连续战斗中ESC打开暂停菜单，stage_map模板误匹配
- **结果**: 碰巧ESC关闭了菜单回到战斗
- **改进方向**: 添加暂停菜单模板（"退出战斗"文字），与stage_map区分

## 做不到的部分 ❌

### 1. 关卡节点定位
- **现状**: 6-10坐标硬编码(1200,310)
- **需求**: 识别地图上未通关节点（灰色三角）并点击
- **方案**: 
  - 模板匹配灰色三角图标 → 获取坐标
  - 或OCR识别节点编号 → 定位
  - 始终滑到最右端找最新节点

### 2. 章节完成检测
- **现状**: 打完后进入下一章地图，脚本空转8分钟
- **需求**: 识别"当前章节已全部通关"或进入了新章节
- **方案**:
  - 检测章节号变化（OCR中央卡片章节名）
  - 检测收集度变化（从65%→100%）
  - 或在stage_map长时间无战斗时退出

### 3. 复活次数/失败管理
- **现状**: 无限复活
- **需求**: 设置复活上限（如3次），超过则放弃
- **方案**: 计数器 + mission_failed后退出

### 4. 体力管理
- **现状**: 无检测
- **需求**: 体力不足时自动补充（冷却剂/每日补给）
- **方案**: 连续战斗提示时检测体力数字 → 不足则进入补充流程

### 5. 未见过的弹窗
- **列表**: 升级奖励、成就通知、新角色解锁、活动弹窗、每日登录奖励
- **方案**: 
  - 通用"关闭"按钮模板（X按钮/ESC）
  - 通用"确定"按钮模板
  - unknown轮转的Space/ESC可部分覆盖

### 6. 探索节点导航
- **现状**: 随机W前进
- **需求**: 检测交互物体方向并导航
- **方案**:
  - HSV颜色检测发光物体 → 计算屏幕位置 → 调整方向
  - 或Q/E旋转视角扫描 + W前进的系统策略
